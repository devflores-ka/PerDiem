# Contribuciones a A PerDiem

¡Gracias por tu interés en contribuir a **A PerDiem**! Este proyecto busca conectar personas que requieren servicios con quienes los ofrecen, de forma simple, justa y segura. Aunque no todo puede estar completo desde el inicio, creemos que podemos construir algo valioso con la colaboración de todos.

## Antes de comenzar

Si deseas proponer una funcionalidad o realizar un cambio importante, por favor abre primero una **issue** para discutirlo. Así evitamos retrabajos o aportes que puedan no alinearse con la visión del proyecto.

## Cómo contribuir

### Código

Las contribuciones de código se hacen a través de *pull requests*. Para hacerlo:

1. Realiza un **fork** de este repositorio.
2. Crea una nueva rama desde `main`.
3. Realiza los cambios necesarios en tu entorno local.
4. Asegúrate de que el proyecto compile correctamente y que tus cambios estén probados.
5. Abre un *pull request* describiendo claramente qué hiciste y por qué.

> Sugerencia: Usa el proyecto en modo desarrollador y la app de ejemplo para verificar tus cambios.

### Documentación

Si implementas una nueva funcionalidad o cambias el comportamiento de alguna existente, también deberás actualizar la documentación correspondiente. Esto asegura que otros puedan comprender y utilizar correctamente lo que construiste.

### Reportar errores

Puedes contribuir reportando errores que encuentres. Para hacerlo de forma efectiva, asegúrate de incluir:

* Descripción clara del problema.
* Pasos para reproducirlo.
* Comportamiento esperado vs comportamiento actual.
* Información técnica relevante (plataforma, logs, etc.).

## Otras formas de ayudar

No todo es código. Puedes ayudar de muchas maneras:

* Probando nuevas versiones y reportando problemas.
* Proponiendo ideas de mejora o nuevas funcionalidades.
* Compartiendo el proyecto con otros.
* Escribiendo tutoriales o explicando cómo usar A PerDiem.
